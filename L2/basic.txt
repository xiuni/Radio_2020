帧结构
1. 一个系统帧是10ms， 分10个子帧 subframe ，每个subframe   1ms
每个子帧中包含几个slot，是根据子载波间隔来定的，子载波间隔定义为
△f = 2^N * 15KHz
所以是： 
子载波间隔 15KHZ的， N=0， 一个subframe中   2^N = 1 个 slot，  一个系统帧10个slot
子载波间隔 30KHZ的， N=1， 一个subframe中   2^N = 2 个 slot， 一个系统帧20个slot  <6G  FR1
子载波间隔 120KHZ的， N=3， 一个subframe中  ^N = 8 个 slot， 一个系统帧80个slot   >6G  FR2
Nokia 5G 中定义了 6G 以下的频段， N=1； 即 30KHz
6G～100G的， N=3; 即 120KHz
有一个比较特殊的，就是SS block 的子载波间隔，即小区中心频点的用作小区搜索和同步的子载波，他们的间隔如下：
6G 以下： 30KHz
6G～100G， 240KHz （普通的是120KHz）
每个slot 包含 14 个 symbols (固定)
每个RB 包含 12 个 subcarrier (固定)

调度单位： 5G 以slot 为调度单位

信道质量不好，MCS 调制低一些，传输的TB size 小一些，冗余数据更多，  重传少一些

○ PDCCH 携带  DCI， gNB 下发的调度信息
DL DCI       1_0 for Msg2             1_1 for other， 用于分配PDSCH
UL DCI       0_0 for Msg3 retransmission       0_1 for other   用于PUSCH 传输
○ PUCCH 携带 UCI，主要用来携带HARQ/SR detection， UE 上报
PUCCH is located in the 14th symbol of all slots except PRACH slots. One UE can use one PUCCH symbol 
Format 0   transmission is over 1 symbol and number of UCI bits is 1 or 2
Format 2  transmission is over 1 symbol (over 1 to 16 PRBs) and number of UCI bits is  in range [3..50]. 可用作CSI report
○ PUCCH 仅在pCell 上传输（CA的情况），所以sCell的harq feedback 要使用Joint-UCI
○ SlotTypeSelector 确定slot pattern 模型， 在一个slot pattern 内的每个slot 是什么类型的： UL/DL 还是SSB或者是PRACH，CSIRS

	ü k0, timing between PDCCH to PDSCH, is mandatory set to 0. Meaning PDCCH & PDSCH are transmitted on same slot.   下行DCI 和 下行数据在同一个slot 传输,即k0=0
	ü k1, timing between PDSCH to PUCCH, is either set to k1Min or k1Min+1 slots. Meaning PUCCH is transmitted k1Min or k1Min+1 slots after the PDSCH transmission.
          下行ACK（PUCCH）延时， 在PDCCH 里面携带（与下行DCI ） K1 {0…15}
	ü k2, timing between PDCCH to PUSCH, is set such a PUSCH is scheduled by a PDCCH transmitted on the previous UL Slot.
